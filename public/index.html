How these numbers are calculated

Contained
The conversation never reached a queue or an agent after the bot session. When Genesys has no conversation detail for a session, a disconnect inside the bot counts as contained and an exit back to the flow counts as escalated.
Reached an agent
An agent connected to the conversation that included the bot session.
Query self-service rate
Customer questions the bot marked as self-served, divided by all questions it handled (Genesys oBotSessionQuerySelfServed / oBotSessionQuery).
Intent recognized
Sessions where the bot matched at least one intent, from either turn data or Genesys's session totals.
Intents in a session
A bot that loops, such as Navigator, can match several intents in one session. Every one is kept: the session counts under each intent it matched, the Intent filter finds a session by any of them, and the session list shows them in the order they were recognized (A → B). Matches counts every recognition, including the same intent matched twice in one session. The order and repeats come from turn-level data, which Genesys keeps for about 10 days; intents that only Genesys's session totals record (such as knowledge matches, or anything older than the turn data) are listed after the ordered ones.
Preview sessions
Sessions started from preview (test) mode in Architect. They have no real conversation, so they are left out by default; the Preview sessions filter can include them or show only them.
Bot response time
For each customer turn, the time from when Genesys captured the customer's input until the bot had its reply ready. The greeting is not counted. Median and longest are taken across every turn in the selection, so they apply per org, per virtual agent or per session depending on the filters. Genesys appears to keep turn-level data for only about the last 10 days, and sessions where the customer never replied have no turn to time, so these figures cover only the sessions that have turn data.
Recognition failure
Sessions with at least one no-match or no-input event.

What each reason means

Each escalated session’s bot transcript (with card numbers and PINs masked) is read by Claude, which picks the reason and writes a short explanation. When Genesys no longer has the transcript, its own AI summary of the conversation is used instead. Results are saved on the server, so a session is only analyzed once.
